# 图匠（macOS / Windows）

一款完全本地运行的图片批处理工具，不需要联网，也不需要上架应用商店。macOS 使用 SwiftUI 原生版本，Windows 提供 ARM64 与 x86 可构建版本。

Windows 源码与构建说明见 [`windows/README.md`](windows/README.md)。

应用配有原创 macOS 图标，主视觉结合图片画布、裁切缩放与重命名输入。

## 功能

- 批量更名：实时预览、模板变量、序号、前后缀、指定位置插入字符、普通/正则替换、大小写、常用扩展名按钮、冲突检查、一次撤销。
- 调整尺寸：实时画面与像素预览、锁定比例只改长边、自定义宽高、百分比、适应边界、填充裁剪、精确拉伸、小图不放大。
- 快捷方案：可命名保存更名参数或完整的尺寸/格式/质量/输出参数，下次启动继续使用。
- 图片输出：保持原格式或转为 JPEG / PNG / HEIC / TIFF，可调整 JPEG/HEIC 质量。
- 文件导入：选择图片、递归导入文件夹、拖放导入。
- 原名输出：尺寸处理保持原文件名；目标目录存在同名图片时以最新结果覆盖。
- 批量选择：支持 Shift 连续选择、Command 多段起止选择，以及 `⌘↩︎` 将所选行设为处理范围。

## 构建与运行

在终端进入项目目录后执行：

```bash
./scripts/build-app.sh
open "dist/图匠.app"
```

需要安装 Xcode（脚本会自动识别正式版或 Beta 版）。

生成的 `dist/图匠.app` 可直接拖到“应用程序”文件夹。应用使用本机临时签名，不依赖 App Store。

首次在其他 Mac 打开时，如系统拦截，请在 Finder 中按住 Control 点击应用，选择“打开”。

## 更名模板

支持 `{name}` 原文件名、`{ext}` 原扩展名、`{parent}` 所在文件夹、`{index}` 序号、`{date}` 修改日期、`{width}` 宽度与 `{height}` 高度。
